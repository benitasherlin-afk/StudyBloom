STUDYBLOOM - COMPLETE CLEAN VERSION

This folder is the complete project. You do not need to mix files from older versions.

FEATURES
1. AI Tutor
2. AI Study Planner
3. AI Quiz Generator
4. Quiz scoring and weak-topic detection
5. Local AI using Ollama + Llama 3.2

REQUIREMENTS
- Node.js
- Express
- Ollama
- Llama 3.2

FIRST TIME SETUP
Open PowerShell in this folder and run:
npm.cmd install express

RUN
node server.js

Then open:
http://localhost:3000

IMPORTANT
Keep Ollama running while using AI Tutor, Planner, or Quiz.

If you already have a working node_modules folder, keep it.
